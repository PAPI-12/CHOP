# Hero plates

The homepage hero is the **original photograph** (`public/images/hero-landscape-*.webp`)
with, on desktop only, an erasable rain pane drawn over it on a canvas. Both
are generated by the scripts here; nothing is hand-painted.

## 1. The photograph — `build-hero-plate.py`

Tiers 3840 / 2560 / 1920 / 1280 are rebuilt at true high resolution from 4×
learned super-resolution masters, not upsampled from a compressed file:

- `upscale.py` runs an NCNN Real-ESRGAN-family model on the CPU, tiled so it
  fits in ~2 GB. Each tile is self-checked against a cubic upscale and re-run
  if it comes back corrupt. Models come from Upscayl's repo (see the
  docstring). The hero uses `high-fidelity-4x`.
- The portrait (`public/images/Hero image.webp`) and the outpainted wall
  strip of `source/hero-landscape-reference-2560.webp` (x ≥ 1760) are each
  upscaled 4×.
- The builder registers the portrait onto the reference landscape (SIFT +
  RANSAC similarity, ~0.15 px median on the face). That keeps the geometry the
  rain pane and the earring stud were authored against. It then matches the
  grade with a least-squares colour matrix and lays the original's own
  micro-texture (pores, stubble, weave) back over the upscale. It finishes a
  3840 master with a light unsharp mask and fine luma grain, then
  area-samples the smaller tiers from it.

```bash
pip install numpy opencv-python-headless ncnn
python3 tools/hero/upscale.py MODELS/high-fidelity-4x "public/images/Hero image.webp" /tmp/portrait-x4.png
python3 -c "import cv2; L=cv2.imread('tools/hero/source/hero-landscape-reference-2560.webp'); cv2.imwrite('/tmp/strip.png', L[:, 1760:])"
python3 tools/hero/upscale.py MODELS/high-fidelity-4x /tmp/strip.png /tmp/strip-x4.png
python3 tools/hero/build-hero-plate.py /tmp/portrait-x4.png /tmp/strip-x4.png
# PLATE_OUT=/tmp/plate python3 tools/hero/build-hero-plate.py …   # dry run elsewhere
```

The portrait master takes ~20 min on 2 CPUs; the strip ~7 min.

## 2. The rain pane — `build-rain-pane.py`

`public/images/hero-rain-pane-{2560,1920,1280}.webp` is the new 2560 plate
seen through rained-on glass, rendered optically: fogged glass with
condensation, lens-like drops (inverted, sharper scene inside, refractive rim,
glint, caustic), and runnels with cleared wet tracks. Run it **after** the
photograph so the pane is built on the same plate.

```bash
python3 tools/hero/build-rain-pane.py               # writes all three tiers
HERO_PREVIEW=/tmp/pane.png python3 tools/hero/build-rain-pane.py   # preview only
```

## Budgets

`npm run smoke` checks every hero WebP's real width against its srcset
descriptor, and checks sizes: photograph tiers < 720 KB (only Retina/4K
screens fetch the 3840 tier), pane tiers < 460 KB.

The What I Do book's 2× plates are made the same way by
`tools/wid/build-wid-plates.py` (fast `upscayl-lite-4x` model).
